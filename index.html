Java

Java como mi lenguaje de programación principal es el que tengo mejor estudiado, es uno de mis lenguajes mas fuertes y es mi favorito

Python

Python como mi lenguaje secundario es el que estoy por el momento aprendiendo, es un lenguaje de programación versátil y fácil de aprender, ideal para desarrollo web, ciencia de datos y automatización.

Html

Html es el lenguaje de marcado fundamental para la creación de páginas web, es la base sobre la cual se construyen los sitios web y es esencial para el desarrollo frontend.

CSS

CSS (hojas de estilo en cascada) es el lenguaje de estilo utilizado para describir la presentación de un documento escrito en HTML. Es esencial para el desarrollo frontend y permite crear diseños atractivos y responsivos.

JavaScript

JavaScript es un lenguaje de programación interpretado, dinámico y multiplataforma que se utiliza principalmente para el desarrollo web frontend, pero también puede ser utilizado para el desarrollo backend con Node.js.

MySQL

Una base de datos es un sistema organizado para almacenar, gestionar y recuperar información de manera eficiente. Es fundamental en el desarrollo de aplicaciones web y móviles.
